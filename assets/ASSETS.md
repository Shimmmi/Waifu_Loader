# ASSETS

Every third-party asset must be logged here: file, source, author, license,
link. Placeholder art is generated by code/tools (spec §16.3) and needs no entry.

## Fonts

| File | Author | License | Link |
| --- | --- | --- | --- |
| `assets/fonts/PixelifySans-Regular.ttf` | Google Fonts (Pixelify Sans) | OFL 1.1 | https://fonts.google.com/specimen/Pixelify+Sans |
| `assets/fonts/PressStart2P-Regular.ttf` | CodeMan38 (Press Start 2P) | OFL 1.1 | https://fonts.google.com/specimen/Press+Start+2P |

**Bundled** — these two files ship in `assets/fonts/` and are picked up
automatically by `ThemeFonts.apply()` (body font → theme default, anti-aliasing
and sub-pixel positioning off). Both were checked to contain Cyrillic (`А Я ё`),
since RU is the primary locale. No code change is needed to add or replace them.

## Исходные изображения, созданные генератором ИИ

Исходный арт, сгенерированный вне игры (ТЗ v0.3 §3 / §0.3), хранится в `art_src/gen/<race>/<class>/`.
Каждое изображение записывается в `docs/art/GENLOG.md` с указанием сервиса/модели, seed и условий использования.
В экспорт игры эти файлы **не попадают** (`exclude_filter` пресета Web: `art_src/*, docs/*`).
Промпты: `docs/art/PROMPTS_LOADERS.md`. Вызовов ИИ из игры нет.
